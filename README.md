# 🎓 Campus Course Records Manager

> A smart and efficient web-based academic management system for managing student records, courses, enrollments, and academic data through a centralized platform.

---

## 📌 Overview

Campus Course Records Manager is a full-stack academic management system developed to simplify and automate campus record management processes.

The system allows administrators and users to:

- Manage student records
- Handle course information
- Maintain enrollment details
- Perform CRUD operations
- Store and organize academic data efficiently
- Provide a clean and user-friendly interface

This project was built to improve understanding of:

- Full Stack Web Development
- Database Management Systems
- CRUD Operations
- Frontend & Backend Integration
- Authentication Systems
- Responsive UI Design

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Kaushal1905/Campus-Course-Records-Manager-.git
```

---

## 2️⃣ Move Project to XAMPP

Move the project folder into:

```bash
xampp/htdocs/
```

---

## 3️⃣ Start XAMPP

Start the following services:

- Apache
- MySQL

---

## 4️⃣ Setup Database

- Open **phpMyAdmin**
- Create a new database
- Import the `.sql` file from the `database` folder

---

## 5️⃣ Run the Project

Open your browser and visit:

```bash
http://localhost/Campus-Course-Records-Manager-/
```
